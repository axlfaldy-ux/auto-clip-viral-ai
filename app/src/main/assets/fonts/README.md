# Bundled subtitle fonts

All eight font files are bundled with the APK and loaded from this directory for both the Subtitle Studio preview and Media3 video rendering.

| Preset | Font file | Typeface family | License |
|---|---|---|---|
| Classic | `classic-roboto.ttf` | Roboto | Apache-2.0; [upstream license](https://github.com/googlefonts/roboto-2/blob/main/LICENSE) |
| Bold Viral | `bold-source-sans.ttf` | Source Sans Pro | SIL Open Font License 1.1; [upstream](https://github.com/adobe-fonts/source-sans/blob/release/LICENSE.md) |
| Elegant | `elegant-noto-serif.ttf` | Noto Serif | SIL Open Font License 1.1; [upstream](https://github.com/notofonts/latin-greek-cyrillic/blob/main/OFL.txt) |
| Typewriter | `typewriter-cutive-mono.ttf` | Cutive Mono | SIL Open Font License 1.1; [upstream](https://github.com/google/fonts/tree/main/ofl/cutivemono) |
| Modern | `modern-roboto-flex.ttf` | Roboto Flex | SIL Open Font License 1.1; [upstream](https://github.com/google/fonts/tree/main/ofl/robotoflex) |
| Rounded | `rounded-coming-soon.ttf` | Coming Soon | SIL Open Font License 1.1; [upstream](https://github.com/google/fonts/tree/main/ofl/comingsoon) |
| Cinematic | `cinematic-dancing-script.ttf` | Dancing Script | SIL Open Font License 1.1; [upstream](https://github.com/google/fonts/tree/main/ofl/dancingscript) |
| Impact | `impact-carrois-gothic.ttf` | Carrois Gothic SC | SIL Open Font License 1.1; [upstream](https://github.com/google/fonts/tree/main/ofl/carroisgothicsc) |

The OFL font files may be bundled and redistributed with software. The corresponding copyright and license texts are maintained by the upstream font projects linked above.
